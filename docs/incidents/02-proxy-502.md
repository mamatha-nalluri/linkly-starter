# Incident 02 — Nginx returns 502 with the laptop-only API command

**Symptom:** Nginx returns 502 while forwarding to `api:5000`.

**Reproduction:** Start proxy without attaching it to the API's network and request an API route. Save response and container logs as `docs/evidence/incident-02.log`.

**Root cause:** The proxy cannot resolve/reach the API unless both share a Docker network; Gunicorn must also bind to `0.0.0.0:5000`, not loopback.

**Fix:** Build the API image and run Gunicorn on `0.0.0.0:5000`. Attach proxy and API to `dmz`; API additionally joins `internal`.
